## 🎯 How to Use This Documentation

### For Your Portfolio Website

1. **Project Card:**
   - Use `metadata.json` to populate project summary
   - Features: `metadata.features[]`
   - Tech stack: `metadata.techStack[]`
   - Short description: `metadata.shortDescription`

2. **Project Detail Page:**
   - Hero section: Use `overview.md` introduction
   - Features section: Use `features.md` content
   - Tech section: Use `architecture.md` overview
   - CTA: Link to GitHub from `metadata.github`

3. **Screenshots:**
   - Add to `screenshots/` folder
   - Reference in documentation
   - Display in portfolio gallery

### For README/Documentation

- Copy relevant sections to main `README.md`
- Use `setup.md` for installation instructions
- Link to detailed docs in `.website/` for deep dives

### For Presentations

- Use `architecture.md` diagrams
- Reference `performance.md` metrics
- Showcase features from `features.md`
- Demo video from `media.md`

VoiceMatter

Press-to-record Linux voice dictation daemon: Deepgram STT + Anthropic-compatible LLM formatter, with a frameless PySide6 overlay and auto-paste via ydotool.

Source on GitHub ↗

Overview

VoiceMatter is a Linux desktop daemon that listens when you press a key, transcribes what you said, runs the transcript through an LLM to clean it up, and pastes the polished result into whichever application you're working in. It is a single-user, always-available dictation layer that sits between your microphone and your editor.

Technology stack

  • Python 3.11+
  • PySide6 (Qt 6)
  • sounddevice (PortAudio)
  • NumPy
  • Deepgram Nova-3 SDK
  • Anthropic SDK
  • wl-copy (Wayland clipboard)
  • ydotool (synthetic input)
  • PipeWire + WirePlumber
  • Unix domain sockets (AF_UNIX)
  • python-dotenv
  • uv package manager

Features

  • Press-to-record hotkey daemon

    KDE-bound F8/F9/Esc survive alt-tab and reboots

  • Deepgram Nova-3 transcription

    Fast multi-lingual STT with smart_format

  • LLM-powered formatter

    Editor-not-writer prompt that drops filler + fixes grammar

  • Auto-copy + auto-paste

    wl-copy to clipboard, ydotool for synthetic Ctrl+V

  • Floating PySide6 overlay

    Frameless pill with live audio meter, 6 visual states

  • KDE global hotkeys

    Absolute-path CLI subcommands: trigger / pause / cancel / stop

Requirements

  • Arch Linux
  • Fedora — 35+
  • Ubuntu — 22.04+
  • Debian — 12+
  • KDE neon
  • Python 3.11+
  • uv 0.4+
  • PipeWire 0.3.50+
  • WirePlumber 0.4+
  • wl-clipboard 2.0+
  • ydotool 1.6+
  • Deepgram API key — Nova-3 speech-to-text
  • Anthropic-API-compatible LLM endpoint — Transcript formatting

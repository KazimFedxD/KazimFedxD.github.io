FxPy - Custom Programming Language

A dynamically-typed, interpreted programming language built from scratch in Python with support for functions, control flow, modules, and comprehensive error reporting.

Source on GitHub ↗

Overview

FxPy is a custom-built, dynamically-typed interpreted programming language implemented entirely in Python. Born from the desire to understand how programming languages work under the hood, FxPy demonstrates the complete process of language design and implementation—from lexical analysis to code execution. The language features a clean, Python-inspired syntax while implementing its own unique characteristics, including a powerful module system, variadic functions, and comprehensive error reporting. FxPy serves both as a functional programming language and an educational resource for understanding compiler/interpreter design.

Technology stack

  • Python
  • Lexer
  • Parser
  • Interpreter
  • AST

Problem it solves

Understanding how programming languages work is often abstract and theoretical:

  • Conceptual Gap: Most developers use languages without understanding parsing, ASTs, and execution models
  • Complex Setup: Professional compilers/interpreters have thousands of dependencies and complex build systems
  • Limited Examples: Few complete, readable language implementations exist for learning
  • Incomplete Tutorials: Most teaching resources show toy calculators, not full languages
  • Hidden Internals: Production languages optimize readability away in favor of performance

Features

  • Dynamic Type System with Runtime Checking

    FxPy implements a dynamic type system where variables can hold any type of value, and type checking happens at runtime rather than compile time. The language supports Numbers (integers and floats), Strings, Lists, Dictionaries, and Functions as first-class values.

  • First-Class Functions with Closures

    Functions in FxPy are first-class citizens—they can be assigned to variables, passed as arguments, returned from other functions, and maintain closure over their defining scope. The language supports both traditional function syntax and arrow function syntax.

  • Advanced Module System with Import Resolution

    FxPy features a sophisticated module system that supports importing code from other .fx files with multiple import syntaxes: basic imports, aliased imports, and selective imports. The system uses relative path resolution based on the importing file's location.

  • Variadic Functions with *args and **kwargs

    FxPy supports variadic functions through *args for collecting positional arguments and **kwargs for collecting keyword arguments. This allows functions to accept flexible numbers of parameters.

  • Rich Error Reporting with Visual Context

    FxPy provides comprehensive error reporting that shows exactly where errors occur in source code, with visual indicators pointing to the problematic location. Errors include position information, context, and helpful messages.

  • Interactive REPL with Live Feedback

    FxPy includes an interactive Read-Eval-Print Loop (REPL) that allows developers to execute code line-by-line and see immediate results. Perfect for experimentation, learning, and quick calculations.

  • Rich Data Structures (Lists & Dictionaries)

    FxPy provides built-in support for two essential data structures: Lists (ordered collections) and Dictionaries (key-value mappings). These structures support intuitive operations and can be nested for complex data modeling.

  • Control Flow Structures

    FxPy supports comprehensive control flow mechanisms including conditional statements (if/elif/else), iteration loops (for, while), and flow control keywords (break, continue, return).

Technical architecture

FxPy follows a classic three-phase interpretation pipeline, transforming source code into executable instructions through distinct stages. This architecture is modular, with each phase handling a specific responsibility in the language processing workflow.

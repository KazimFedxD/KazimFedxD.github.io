# Configuration Samples

These are sanitized configuration files from the TeachBack project.
**All sensitive information has been replaced with placeholders.**

## Files Included

| File | Description |
|------|-------------|
| `package.json` | Frontend Node.js dependencies |
| `requirements.txt` | Backend Python dependencies |
| `docker-compose.yml` | Docker services configuration |

## Usage

These files are provided as reference for:
- Understanding project dependencies
- Replicating the development environment
- Learning the project structure

## Important Notes

⚠️ **Do not use these files directly in production.**

All sensitive values have been replaced:
- API keys → `YOUR_API_KEY_HERE`
- Passwords → `your-password-here`
- Database URLs → Generic placeholders

Before using, replace all placeholders with your actual credentials.

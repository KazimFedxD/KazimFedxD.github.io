# TeachBack Future Enhancements

## Roadmap

### Version 2.0 (Q2 2026)

#### Core Platform Improvements
- [ ] **Multi-language Support** — Support for teaching in languages other than English
- [ ] **Mobile Native Apps** — iOS and Android applications
- [ ] **Offline Mode** — Record sessions offline, sync when connected
- [ ] **Dark/Light Theme Toggle** — User preference for UI theme

#### Learning Features
- [ ] **Topic Library** — Pre-defined topics with subtopic guidance
- [ ] **Learning Paths** — Structured curriculum sequences
- [ ] **Progress Tracking** — Long-term mastery tracking across topics

## How to Contribute Ideas

Have a feature idea? Here's how to share:

1. **GitHub Issues** — Open a feature request issue
2. **Discussions** — Start a discussion thread
3. **Email** — Contact the maintainers directly

When submitting ideas, please include:
- **Problem**: What problem does this solve?
- **Solution**: How do you envision it working?
- **Impact**: Who benefits and how?
- **Alternatives**: Other ways this could be addressed?

## Guidelines

### Image Quality
- **Resolution**: 1920x1080 minimum
- **Format**: PNG for screenshots, GIF for animations
- **Theme**: Discord dark mode
- **Clarity**: Sharp, readable text

### Content Standards
- ✅ Use dummy/test data (not real user information)
- ✅ Clear demonstration of feature
- ✅ Professional presentation
- ❌ No sensitive information (tokens, real user IDs)
- ❌ No profanity or inappropriate content

### File Naming
- Use lowercase with hyphens
- Descriptive names
- Consistent format
- Examples: `setup-wizard.png`, `api-chatgpt.gif`

### File Size
- **PNG**: Optimize for web (use TinyPNG.com if needed)
- **GIF**: Keep under 5 MB (use ezgif.com/optimize)

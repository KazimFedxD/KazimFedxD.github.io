## Screenshot Guidelines

- **Resolution**: 1920x1080 minimum for desktop, 375x812 for mobile
- **Format**: PNG for screenshots, GIF for animations
- **Quality**: High quality, no compression artifacts
- **Content**: Use realistic but anonymized data (no real emails/passwords)
- **Browser**: Use Chrome for consistency
- **File Size**: Keep PNGs under 2MB, GIFs under 5MB

## Tools Recommended

### Screenshot Capture
- **macOS**: Cmd+Shift+4 (built-in)
- **Windows**: Snipping Tool, Win+Shift+S
- **Linux**: GNOME Screenshot
- **Browser Extension**: Awesome Screenshot

### GIF Recording
- **ScreenToGif** (Windows)
- **Kap** (macOS)
- **LICEcap** (cross-platform)

### Image Optimization
- **TinyPNG** - https://tinypng.com/
- **ImageOptim** (macOS)

## 📝 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --primary: #6366f1;
    --secondary: #ec4899;
    --accent: #8b5cf6;
    ...
}
```

### Content
Update information in respective HTML files:
- Personal info, education, experience
- Project details and links
- Skills and proficiencies
- Contact information

### Contact Form
Configure EmailJS in `contact.js`:
- Update service ID
- Update template IDs
- Customize email templates
